# Persistência

O Harpia Arch usa Hibernate ORM com JPA tradicional do Quarkus. Panache não é obrigatório.

## Dependências

No POM da aplicação:

```xml
<dependency>
    <groupId>io.quarkus</groupId>
    <artifactId>quarkus-hibernate-orm</artifactId>
</dependency>
<dependency>
    <groupId>io.quarkus</groupId>
    <artifactId>quarkus-jdbc-postgresql</artifactId>
</dependency>
<dependency>
    <groupId>io.quarkus</groupId>
    <artifactId>quarkus-flyway</artifactId>
</dependency>
```

## Separação de camadas

```text
Controller  -> DTOs HTTP (gerados)
Workflow    -> modelo interno / Activities
Activity    -> regra de negócio
Repository  -> EntityManager / JPA
Entity      -> tabela
```

Não reutilize DTOs HTTP como entidades JPA.

## Entity

```java
@Entity
@Table(name = "customers")
public class CustomerEntity {

    @Id
    @GeneratedValue(strategy = GenerationType.IDENTITY)
    private Long id;

    @Column(nullable = false, length = 150)
    private String name;

    @Column(nullable = false, length = 11, unique = true)
    private String document;

    protected CustomerEntity() {
    }

    public CustomerEntity(String name, String document) {
        this.name = name;
        this.document = document;
    }

    public Long getId() {
        return id;
    }

    public String getName() {
        return name;
    }
}
```

## Repository

```java
@Repository
public class CustomerRepository {

    private final EntityManager entityManager;

    public CustomerRepository(EntityManager entityManager) {
        this.entityManager = entityManager;
    }

    public CustomerEntity save(CustomerEntity customer) {
        entityManager.persist(customer);
        entityManager.flush();
        return customer;
    }

    public Optional<CustomerEntity> findById(Long id) {
        return Optional.ofNullable(entityManager.find(CustomerEntity.class, id));
    }
}
```

## Activity transacional

```java
@Activity
public class PersistCustomerActivity
        implements FlowItem<CustomerInput, CustomerContext, CustomerEntity> {

    private final CustomerRepository repository;

    public PersistCustomerActivity(CustomerRepository repository) {
        this.repository = repository;
    }

    @Override
    @Transactional
    public CustomerEntity execute(CustomerInput input, CustomerContext context) {
        return repository.save(new CustomerEntity(input.name(), input.document()));
    }
}
```

A transação é delimitada **explicitamente** na camada escolhida. O framework não abre uma
transação por Activity automaticamente.

## Workflow

```java
@WorkflowDefinition
public class CreateCustomerWorkflow
        extends Workflow<CustomerInput, CustomerContext, CustomerEntity> {

    private final PersistCustomerActivity persist;

    public CreateCustomerWorkflow(PersistCustomerActivity persist) {
        this.persist = persist;
    }

    @Override
    protected void configure() {
        flowBuilder = FlowBuilder.builder(CustomerInput.class, CustomerContext.class)
                .step(persist)
                .build();
    }
}
```

## Schema

Use migrações (Flyway ou Liquibase) para evoluir o banco. O Hibernate deve ficar com schema
gerenciado externamente:

```yaml
quarkus:
  hibernate-orm:
    database:
      default-schema: user_info
    schema-management:
      strategy: none
  flyway:
    migrate-at-start: true
    schemas: user_info
```

```sql
create table customers (
    id bigint generated by default as identity primary key,
    name varchar(150) not null,
    document varchar(11) not null,
    criado_em timestamp with time zone not null default now()
);

create unique index uk_customers_document on customers (document);
```

## Objetos compostos

Endereço e chaves podem ser `@Embeddable`:

```java
@Embeddable
public class AddressEmbeddable {

    @Column(length = 8)
    private String zipCode;

    @Column(length = 200)
    private String street;

    protected AddressEmbeddable() {
    }

    public AddressEmbeddable(String zipCode, String street) {
        this.zipCode = zipCode;
        this.street = street;
    }
}
```

Coleções usam `@OneToMany` com cascade/orphan removal:

```java
@OneToMany(mappedBy = "customer", cascade = CascadeType.ALL, orphanRemoval = true)
private List<DependentEntity> dependents = new ArrayList<>();
```
