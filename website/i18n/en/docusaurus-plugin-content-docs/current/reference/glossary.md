# Glossary

| Term | Definition |
|---|---|
| **Activity** | Executable unit with a cohesive responsibility. Implements `FlowItem` or `SimpleFlowItem` and is annotated with `@Activity`. |
| **ArC** | Quarkus CDI container. Discovers beans and stereotypes at build time. |
| **Builder** | Immutable object that accumulates steps and returns a composition. `FlowBuilder` and `SimpleFlowBuilder` are the public builders. |
| **CDI** | Contexts and Dependency Injection. Harpia Arch uses `@ApplicationScoped` stereotypes to register beans. |
| **Composition** | Immutable chain of steps. Each `.step()` creates a new typed composition. |
| **Context** | Object shared between the steps of an execution. It can be real, `Void` or absent. |
| **Contract First** | Approach in which the OpenAPI contract generates the HTTP interfaces and the DTOs before the Controller. |
| **Deployment** | Quarkus artifact loaded at build time. In Harpia Arch, `harpia-core-deployment` contains validation and build steps. |
| **FlowItem** | Execution contract `execute(input, context)`. |
| **Flow** | Immutable pipeline created by a builder and executed by a Workflow or directly. |
| **Jandex** | Class index used by Quarkus for build-time validation. |
| **JAX-RS** | Jakarta REST API used by the interfaces generated by OpenAPI. |
| **Native Image** | GraalVM AOT compilation that produces a native executable. |
| **Repository** | Persistence component annotated with `@Repository`. It does not depend on Controller, Service or Activity. |
| **Service** | Business rule component annotated with `@Service`. It does not expose HTTP. |
| **SimpleFlowItem** | Activity contract without context; extends `FlowItem<I, Void, O>`. |
| **SimpleWorkflow** | Workflow without context; extends `Workflow<I, Void, O>`. |
| **Stage** | Internal typed closure used by the builder to compose steps. It is not public API. |
| **Stereotype** | CDI annotation that groups other annotations, such as `@ApplicationScoped`. |
| **Void** | Type used to explicitly declare that there is no context. The value received is `null`. |
| **Workflow** | Declarative composition of Activities that is also a `FlowItem`. |
